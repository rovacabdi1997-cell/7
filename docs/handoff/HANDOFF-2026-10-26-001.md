## Codex'in yapacağı tek adım

`frontend/features/data/types.ts` ve `DataProvider.tsx` dosyalarını v2 şemasına geçir. Tip kaynağı `docs/api/openapi.json`, örnekler `docs/api/examples/`. Bu adım bitmeden TV ekranları v2 API ile açılmaz.

## Mod kodları ve ekran metni

API ASCII kod gönderir. Ekran Türkmence metin gösterir. Eşleme frontend'de tek yerde durmalı.

| API kodu | Ekran metni |
|---|---|
| `HAKYKY` | Hakyky |
| `SIMULYASIYA` | Simulýasiýa |
| `KONE` | Köne |
| `MAGLUMAT_YOK` | Maglumat ýok |

## Değişen alanlar

| v1 | v2 | Frontend etkisi |
|---|---|---|
| `mode: "SIMULÝASIÝA" \| "HAKYKY" \| "ÝOK"` | `"SIMULYASIYA" \| "HAKYKY" \| "KONE" \| "MAGLUMAT_YOK"` | Tüm mod karşılaştırmaları |
| `line.status: "RUNNING"` | `line.status.value`, ayrıca `mode`, `sourceTs` | Hat durumu okuması |
| `line.trend: TrendPoint[]` | `line.trend.points` | Saatlik grafik |
| `line.efficiencyPct` | Kaldırıldı. `line.oee.availability / performance / quality / oee` | Verimlilik kartı üç çubuk olur |
| Zaman damgası `+05:00` | UTC, `Z` ile biter | Ekranda Asia/Ashgabat'a çevir |

## Yeni alanlar

| Alan | Not |
|---|---|
| `snapshot.contractVersion` | `"2.0.0"`. Eşleşmezse ekran uyarı göstermeli |
| `snapshot.connection` | `state`: `ONLINE`, `OFFLINE`, `NOT_CONFIGURED`, `SIMULATED`; `lastOkTs` |
| `snapshot.energy.powerKw`, `energyKwhToday` | Sayaç yok, şu an `MAGLUMAT_YOK` |
| `line.shiftOutput`, `line.shiftPlan` | Vardiya üretimi ve hedefi. Günlük alanların yerine kullanılmaz |
| `line.capacityPct`, `line.nominalRate` | Nominal Sanjin kaynaklı, `sourceType: CONFIG` |
| `line.productName` | Her iki hat |
| `line.thicknessMm`, `line.boardType` | Yalnız gipsokarton, gury garyndıda `null` |
| `line.currentStop` | Duruş yoksa `null`. `durationMin` kendi başlangıcından |
| `alarm.priority` | 1 kritik, 2 uyarı, 3 bilgi |
| Her değer alanında `sourceType`, `sourceTs`, `staleAfterSec` | KÖNE hesabı için |

## KÖNE kuralı

- Sunucu her snapshot'ta uygular. `HAKYKY` alanın yaşı `staleAfterSec` değerini aşınca `KONE` gelir. Değer korunur.
- Akış koparsa istemci aynı kuralı uygular: `now − sourceTs > staleAfterSec` ise alanı `KONE` göster.
- `KONE` alan soluk ve işaretli çizilir, yeşil kalmaz. `/api/overview` içindeki `runningLines` sayımına `KONE` hat girmez.
- Sessiz demo geçişi yok. Bağlantı kopunca demo verisine düşülmez.
